# DEBATRİX — Design System

Light mode only. Azerbaijani UI everywhere.

## Colors
- Canvas: #FFFFFF, off-white #F8FAFC
- Borders: #E2E8F0
- Ink (text): #0F172A; secondary text #475569 / #64748B
- RAZISAN (PRO): #2563EB (electric blue)
- RAZI DEYİLSƏN (CON): #DC2626 (coral red)
- Gold / AI Hakim / RIX / champion: #D97706
- Purple accent (AI, Champion frame): #7C3AED

## Typography
- Poppins (display + body). Base text 16px (text-base), metadata 13–14px. No text below 12px except footer (text-xs).
- Line-height generous (leading-relaxed on paragraphs).

## Layout
- Max width 1200px, generous padding, rounded-2xl cards with 1px #E2E8F0 border.
- Section headers: optional banner artwork with light gradient overlay (white → transparent) so text stays crisp.

## Motion
- Staggered fade-up on hero load. Otherwise minimal transitions.

## Components
- Primary button: ink-filled. PRO button blue, CON button red.
- Cards: white, subtle shadow-sm, hover border-slate-300.
